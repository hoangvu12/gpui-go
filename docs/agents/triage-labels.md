# Triage labels

The user selected the default vocabulary.

| Canonical role | Local label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human work |
| `wontfix` | `wontfix` | Will not be actioned |

Use the `Triage:` field in local issue files. Wayfinder type labels and ticket status are separate metadata; see [tracker conventions](issue-tracker.md).
