- **Where the default lives**: `gpui/style.go` `DefaultStyle()` carries `Position: PositionStatic` (D3's second step, the CSS default; the pin's default is Relative — the recorded divergence, noted in the `DefaultStyle` and `Position` docs, `Static()`'s doc, and pinned by `TestStyleToRecordDefaults`: the record maps static onto the pin's Relative tag with the insets zeroed, and the ABI record default stays the pin's).
- **The root is the ICB now**: `drawRoots` marks the root's request walk (`frameDrawState.icbPending`); `openContainingBlock` force-opens the root's scope even when its own style is static (the LayoutView stand-in — always an absolute container), and `requestLayoutOf` discards the flag for a non-participating root (the pin's approximation). A static chain with no positioned ancestor resolves against the window root; the root's own absolute children re-absorb into it (behaviour-preserving for the root).
- **Standalone roots keep their absolutes**: `drawable.layoutAsRoot` requests with the enclosing scopes detached (`withIsolatedContainingBlocks`, containingblock.go) — List/UniformList/virtual-list rows, measured trees, cached-view refreshes and deferred surfaces are their own native roots, so an absolute child of a row stays inside the row ("keep behaving the same"); no wrapper node was added, and the request-phase measure walks can no longer leak deferred children into the live tree's scopes. Discriminated by `TestListRowKeepsItsAbsoluteChildrenUnderTheStaticDefault` (the row states `.Static()` — the codemod's documented escape form).
- **The codemod/check** — `cmd/positioncodemod` (the displaycodemod pattern: `-w`, `-check`, `-v`, go-list package walking, generated-file skip, idempotent): two permanent rules — inset vocabulary without a position (insets are inert under static) and a Div chain attaching an absolute-styled child without stating a position (the pin's default made it the containing block; the fix is `.Relative()`, or `.Static()` to state the escape). Parity fixture packages are exempt from the parent rule (their Chrome pages are the ground truth).
