## 4. Native gaps

There is **one** native gap: a11y publishing of roles and states. Base behaviour is not affected.

- **Roles.** `role_from_tag` accepts only tags 1-8 (Window, GenericContainer, Button, TextInput, TextRun, StaticText→Label, CheckBox, Slider) and returns `ERR_BAD_VALUE` otherwise (`N/a11y.rs:598-613`).
  - On the Go side, `a11yRoleTag` errors for any other role (`G/a11yprovider.go:545-566`), and the error aborts the whole publish (`G/a11yprovider.go:673-675`).
  - Affected roles: ComboBox (select, combobox, date_picker), Tree/TreeItem (tree), RadioButton (color swatch), and Table/RowGroup/Row/ColumnHeader/Cell (table).
- **States.** The node record has only label, description, value, author_id, flags (Hidden=0x1, HasBounds=0x2), actions and children (`internal/native/a11y.go:84-127`). The decoder applies nothing else (`N/a11y.rs:816-870`).
  - expanded, selected, toggled, row/column index and count, and position-in-set/size-of-set therefore cannot reach the OS.
  - Affected: select/date_picker (expanded), tree (selected/expanded), color_picker (selected/toggled/expanded), table (indices/counts), questionnaire (pos/size in set).
- **Not native (checked):**
  - The Click a11y action is publishable. The decoder reads the mask as tag presence (`N/a11y.rs:845-856`).
  - Cursors: `SetCursorStyle` is pure-Go Win32 (`G/desktop_windows.go:442-479`), so C8 is Go-only.
  - Drag, hover, keyed state, refresh, defer and canvas are all scene/dispatch logic in Go.
  - Nothing in this slice paints gradients. color_picker leaves the tracks to the app.
- **Mitigation without the DLL.** Carry the full semantics in the Go a11y snapshot, which is what the tests assert. At publish time, map unsupported roles to GenericContainer (or Button) and drop the unsupported states, instead of erroring. This is a documented deviation and needs a user decision.

Conclusion for chrono: port it. It is about 100 lines of value type plus helpers, and the only open question is the `format` API. No Go module is warranted. Upstream hazard: `month_days()` passes `current_month + n` unwrapped into `days_in_month` (`calendar.rs:318`), so it panics in Rust for month 13. Render uses the wrapped `offset_year_month` (`:737`), so Go should preserve or fix this deliberately.

**palette: color_picker.rs only,** through the core re-exports. Core `Hsla` is `palette::Hsla` and `Rgba` is `palette::rgb::Rgba` (`R/color.rs:7`).

| Use | Where | Colour space / conversion | Go status |
|---|---|---|---|
| `Rgba::new(r,g,b,a).into_color()` → Hsla | `parse_hex` (`color_picker.rs:59-65`) | Srgb → Hsl (same RGB space, no linearization), alpha carried, `FromColor` = unclamped + clamp | PRESENT: `RgbaToHsla(uint32)` is a bit-exact port of palette 0.7.7 Srgb→Hsl (`G/paint.go:109-139`). Conclusion for palette: no module is needed. Only Srgb↔Hsl is used, and that is already ported. Also, `(v*255.) as u32` saturates in Rust; Go needs an explicit clamp before the cast.

**regex: color_picker only.** `regex::Regex::new("^#[0-9a-fA-F]{0,8}$")` is passed to `InputState::pattern` (`:197`). Go `regexp` is RE2 and handles it identically, but the Go input package must expose `Pattern(*regexp.Regexp)`.

**smallvec: color_picker only.** `SmallVec<[AnyElement;2|1]>` for children (`:474,626`) becomes a plain slice.

**Not used in this slice:** rust_decimal (feature `decimal`, plot only), num-traits, itertools, smol, futures, web-time, aho-corasick, unicode-segmentation, serde. `std::time::Duration` (nav_stack `Transition::new(Duration::ZERO)`, `:355-385`) maps to `time.Duration`.

## 6. Internal dependency order

Base-internal prerequisites, from other slices:
- `actions` (Cancel, Confirm{secondary}, SelectUp/Down/Left/Right)

- `slider` (SliderState, SliderEvent)
- `checkbox` (Checkbox, CheckboxState) and `radio` (Radio)
- `init` (lib.rs, tests)

Suggested port order within the slice:

1. **table**: styled and observe only. It is the cleanest pilot for C1 and C13.
2. **date_picker**: actions, styled, observe.
3. **select**, then **combobox**. Combobox renders Select (`combobox.rs:9`).
4. **calendar**: styled, observe, plus the chrono replacement. It is independent of date_picker, which is only a trigger shell.
5. **tree**: actions, styled, observe, and C2/C12/C14.
6. **nav_stack**: after history and motion.
7. **resizable** (mod → panel → resize_handle): after theme, element_ext and geometry, and C4-C10/C17. The **dock** slice depends on it (`resize_handle.rs:117`).
8. **color_picker**: after input (pattern) and slider, and C3/C4/C11/C15.

Hazards to carry into the tickets:
- Several render paths mutate state:
  - tree renders inside the entity it reads.
  - nav_stack sets `transit = None` while rendering.
  - calendar sets the month count while rendering.
- resizable's settle-frame protocol depends on prepaint feedback, `window.defer` and notify running in the right order on the same frame. It also asserts an exact float32 split of 220/180.
- questionnaire's silent-setter test counts events, and Go `Subscribe` activates through a queued defer (`G/event.go:106-110`).
- color_picker's `suppress_input_change` relies on a synchronous InputEvent emit.
